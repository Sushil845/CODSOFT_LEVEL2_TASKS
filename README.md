A modern MERN Stack Job Portal that connects employers and job seekers through a responsive and secure platform.

### ✨ Features

- User Authentication
- Employer Dashboard
- Candidate Dashboard
- Create Job
- Edit Job
- Delete Job
- Browse Jobs
- Apply for Jobs
- View Applicants
- JWT Authentication
- Responsive UI

### 🛠 Tech Stack
